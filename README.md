## 📢 프로젝트 개요

기업의 회의는 많은 시간을 소모하지만 회의록 작성, 업무 분배, 후속 조치 등의 관리 업무가 비효율적으로 처리되어 생산성 저하의 원인이 됩니다.

음성 인식과 AI 기술을 활용해 회의 내용 요약부터 업무 분배, 효율성 분석까지 전체 프로세스를 자동화하여 업무 생산성을 향상시키고자 합니다.
